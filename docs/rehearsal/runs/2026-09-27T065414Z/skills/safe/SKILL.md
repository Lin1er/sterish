# Unit Converter

Convert a quantity between metric and imperial units.

## Usage

Call `convert` with a value, a source unit and a target unit. Call `list_units` to see
what is supported: length (mm, cm, m, km, in, ft, yd, mi), mass (g, kg, oz, lb) and
temperature (C, F, K).

## What it does not do

It is arithmetic only. It opens no network connection, reads no local file and asks for
no account of any kind.
