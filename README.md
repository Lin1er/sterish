# Sterish

> Audited Skill Marketplace for AI Agents on Stellar.

Sterish is a Soroban-based registry, an LLM audit pipeline, and an x402 payment gateway 
allowing AI agents to discover, verify, and pay-per-use for skills/tools safely.

## Project Structure
- `/contracts` — Soroban smart contracts (Registry, Escrow).
- `/backend` — Python FastAPI + LLM Audit Pipeline.
- `/frontend` — Scaffold for future Web Dashboard.
